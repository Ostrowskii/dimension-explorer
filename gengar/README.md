# Gengar

Gengar esculpido com o motor do Ink Studio e exibido como splats gaussianos no Dimension Explorer.

- `gengar.js`: cena procedural (corpo, orelhas, espinhos, braços, pernas; olhos e boca pintados na superfície).
- `node export-scene.js`: regenera `scene-data.js` para o visualizador.
- `gengar.png`: render pixel-art do Ink Studio.

Abra `index.html` para explorar em 3D.
