# Torre no bosque — versão preservada

Abra `dist/index.html` no Chrome com WebGL para explorar a torre. Todos os dados necessários para a visualização estão em `dist/`, incluindo `scene-data.js`. O visualizador funciona sem o projeto irmão e sem acesso à internet.

Esta é a versão fechada da torre, com as paredes renderizadas como superfícies de splats sobrepostos. O comando `npm run build:scene` foi protegido contra a substituição dos dados arquivados. Para criar outras cenas, use outra pasta e outros arquivos de dados.

O código procedural usado para gerar esta versão originalmente está em `../shapeshift-labs-ink-studio/lab/tower-garden.js`. Ele é apenas a fonte histórica; abrir a torre aqui não depende dele.
