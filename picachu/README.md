# Picachu

Apesar do nome, é o Gengar (primeira versão) esculpido com o motor do Ink Studio e exibido como splats gaussianos no Dimension Explorer.

- `picachu.js`: cena procedural (corpo, orelhas, espinhos, braços, pernas; olhos e boca pintados na superfície).
- `node export-scene.js`: regenera `scene-data.js` para o visualizador.
- `picachu.png`: render pixel-art do Ink Studio.

Abra `index.html` para explorar em 3D. A versão detalhada está em `../pikachu/`.
