# Pikachu

Apesar do nome, é o Gengar em versão detalhada: corpo único com membros fundidos (`S.join round`), dentes triangulares encaixados, olhos com contorno, pupila e brilho, garras finas e chão liso simplificado. ~96 mil splats.

- `pikachu.js`: cena procedural.
- `node export-scene.js`: regenera `scene-data.js`.
- `pikachu.png`: render pixel-art do Ink Studio.

A primeira versão está em `../picachu/`.
